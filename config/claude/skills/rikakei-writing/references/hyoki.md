# 表記の細則

『理科系の作文技術』第8章に基づく表記ルール。文章の内容を整えたあと、仕上げとして適用する。

## 字面の「適当な白さ」

漢字を多用すると紙面が「黒く」なり可読性が下がる。接続詞・副詞・補助動詞・形式名詞は原則としてかなで書く(かなに「開く」)。ただし、かなばかりが続いて「白すぎる」文も読みにくい。読みやすさを最優先し、適当な白さを保つ。

### 標準記法(原著 表8.2)

| こうは書かないで | こう書く |
|---|---|
| 及び | および |
| 並びに | ならびに |
| 乃至 | ないし |
| 初めて | はじめて |
| 再び | ふたたび |
| 或る | ある |
| 或いは | あるいは |
| 即ち | すなわち |
| 但し | ただし |
| 然し・併し | しかし |
| 勿論 | もちろん |
| 従って | したがって |
| 殊に | ことに |
| 各々 | おのおの |
| 普通 | ふつう |
| 沢山の | たくさんの |
| 色々の | いろいろの |
| 他の | ほかの |
| 〜の通り | 〜のとおり |
| 〜する時に | 〜するときに(ただし「時とともに」は漢字) |
| 〜である事は | 〜であることは(ただし「事と次第では」は漢字) |
| 〜と共に | 〜とともに |
| 〜に拘らず | 〜にかかわらず |
| 出来る | できる |
| 我々 | われわれ |

形式名詞の「こと」「とき」「ところ」「もの」はかな、実質的な意味をもつ場合(「時とともに」「事件の現場」)は漢字と使い分ける。

漢字だけで書くことばをベタに二つ続けない(例:「衝突直前」のような熟語は別)。続く場合は読点やかなのことばを挟む。

## 受動態を避ける

日本語の文は受動態で書くとひねくれて読みにくくなる。できるだけ能動態で書く。日本語では主語を省略できるので、能動態にしても主語を書く必要はないことが多い。

- 「〜と思われる」「〜と考えられる」→「〜と思う」「〜と考える」(主体が「私」であることは明白)
- 「実験が行われた」→「実験を行った」

能動態にすると読みやすくなるだけでなく、文が短くなることが多い。

## 文末に変化をつける

同じかたちで終わる文を続けない。「〜である。〜である。〜である。」と続くと単調で、教科書風・官庁文書風の固苦しい文章になる。

- 「である」はなるべく使わず「だ」を活用する
- 「であろう」ではなく「だろう」と書く
- 名詞止め、「〜する」「〜だ」「〜という」など述語の形を変えていく

(ただし、です・ます体の文書ではこの項は文体に合わせて読み替える。)

## 書きことばの現代化

死語になりつつある書きことばを避け、話しことばに近い自然な語を使う:

- 「よい」→「いい」(文脈による)
- 「〜してゆく」→「〜していく」
- 「〜より」(起点)→「〜から」
- 「〜のみ」→「〜だけ」

## 図・表

- 図表は、本文を読まなくてもそれだけで内容がわかるように、キャプションと凡例を完備する
- 同じデータを図と表の両方で示さない
- 図は直観的理解に、表は正確な情報の提示に向く。選び抜いたことばによる短い文章のほうが優る場合もある。慎重に選ぶ
- 論文・技術文書では、量の記号は斜体(イタリック)、単位は立体(ローマン体)で書く(例: 長さ *l* = 20 m)

## 一義的に読める文

- 一文を書くたびに、ほかの意味に取られる心配がないかを吟味する
- 修飾語がどのことばに係るのか曖昧な文を避ける(語順の変更・読点・文の分割で解消する)
- 論文・報告書では、使用する記号にはすべて説明を与え、一貫した記号を使う。慣用以外のことばには定義を与える
